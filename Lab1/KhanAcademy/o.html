My First Week Learning HTML

Posted on January 15, 2024

This week I started learning HTML. It is the language used to create web pages. I learned about different tags that make up a webpage.

HTML tags tell the browser how to display content. For example, the h1 tag makes a big heading, and the p tag makes a paragraph.

Here are some basic HTML tags:

  • h1 for main heading
  • p for paragraph
  • a for links
  • img for images

I practiced making simple pages with these tags. I learned how to create links to other websites. I also learned how to add images.

Next week I will learn CSS to make my pages look better.

Building My First Website

Posted on January 22, 2024

This week I built my first complete website. It is a simple recipe website with three recipes.

I used HTML to create the structure of the page. I used headings, paragraphs, lists, and tables. The website has a table of contents that links to each recipe.

I also learned some CSS this week. I learned how to change colors and fonts. I learned how to make text look different with bold and italic styles.

Steps to create internal links:

  1. Add an id to the section you want to link to
  2. Create a link with a # and the id name
  3. The link will jump to that section when clicked

I am happy with my progress. Building a real website helped me understand how HTML and CSS work together.

My next goal is to learn more about CSS layout. I want to learn how to position elements on the page.
